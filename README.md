# FarmCast 🌾

**AI weather intelligence for UK farmers — built at the Lenovo × NVIDIA Hackathon**

FarmCast is a Streamlit dashboard that combines Pangu-Weather forecast data with a local Ollama LLM to give UK farmers a clear, plain-English picture of conditions in their region. At a glance, farmers can see whether it is safe to spray pesticides, run machinery, put livestock out, or plant crops — plus an AI-generated evening advisory tailored to the day's conditions.

---

## Features

- **Decision cards** — four activity verdicts (Good / Caution / Avoid) updated from live forecast data
- **Frost risk alert** — prominent amber banner when overnight frost is forecast
- **AI evening advisory** — 3-sentence plain-English guidance generated by a local Ollama LLM
- **Hourly conditions chart** — dual-axis Plotly chart showing temperature, wind speed, and precipitation probability from 06:00–23:00
- **Interactive UK map** — Folium map with colour-coded region markers; click to switch region

## Setup

### 1. Clone and install

```bash
git clone https://github.com/HiPeople21/LenovoNvidia
cd LenovoNvidia
pip install -r requirements.txt
```

### 2. Pull the Ollama model

Ensure [Ollama](https://ollama.com) is installed and running, then pull the default model:

```bash
ollama pull llama3.2
```

### 3. Run the app

```bash
streamlit run app.py --server.port 8501 --server.address 0.0.0.0
```

Open `http://<server-ip>:8501` in your browser.

## Swapping in real Pangu-Weather data

**Only `data_loader.py` needs to change.**

1. Open `data_loader.py`.
2. Replace the body of `get_forecast(region: str)` with your Pangu-Weather inference call.
3. Ensure the returned dict matches the schema below — nothing else in the project needs to change.

```python
{
    "region":                  str,   # e.g. "East Midlands"
    "forecast_time":           str,   # ISO-8601, e.g. "2026-03-07T18:00:00"
    "temperature_c":           float,
    "wind_speed_kmh":          float,
    "wind_direction_deg":      int,
    "precipitation_mm":        float,
    "precipitation_probability": float,  # 0.0 - 1.0
    "frost_risk":              bool,
    "hourly": [
        {
            "hour":        str,   # "HH:00", 06:00 through 23:00
            "temp_c":      float,
            "wind_kmh":    float,
            "precip_prob": float,  # 0.0 - 1.0
        },
        # 18 entries total
    ]
}
```

## Hackathon context

Built at the **Lenovo x NVIDIA Hackathon** on a Lenovo DGX machine.
The app runs on port 8501 and is accessed via browser over the local network.

Team goal: demonstrate how edge-hosted AI (Pangu-Weather for forecasting, Ollama for narrative) can deliver actionable, low-latency intelligence to farmers without relying on cloud APIs.
